# Localization (5 Locales: en/de/fr/ru/zh)

`Localization/` = `Strings.cs` + `EnumLabels.cs` + 5 locale JSONs (en_GB, de_DE, fr_FR, ru_RU, zh_CN).

- **Locale JSONs are EmbeddedResources** — string changes require rebuild + redeploy; editing the JSONs in the deck's Mods folder does nothing.
- **`.i18n()` falls back to en_GB, then to the raw key** (`Localization/Strings.cs`): en_GB is the mandatory pack; missing keys in other locales degrade gracefully to English. A new key needs en_GB at minimum — other locales are optional (untranslated → English).
- UI strings are English-only in code. No mixed-language — use `Yes`/`No`, `!=`, etc.
- **i18n math-notation properties are LOCALIZED per locale** — never paste en-GB into all 5 files. Existing rows use locale-native abbreviations: de `AB − RK` / `SG − Rettung` / `TW − Gruppe`, fr `BAB − CA` / `DD − Sauvegarde` / `DV − Groupe`, ru `БА − КБ` / `СЛ − Спасбросок` / `КЗ − Группа`, zh mixes native (`生命骰`, `豁免`) with kept-English (`AB − AC`). Copy from existing `ABMinusAC` row in each locale.
- **zh_CN punctuation convention**: ASCII `: , ( )` plus fullwidth `。`; character tabs are `角色页面` (not `页签`). The file deliberately deviates from standard fullwidth zh punctuation — keep new strings consistent.
- New enum members (subjects, properties, conditions) need their i18n keys in all 5 files — the per-feature site checklists are in [`checklists.md`](checklists.md).
- **A localized string that quotes a UI control must quote that locale's own label** — `button.unlink_edit` is translated in all 5 files, so an en-GB label pasted into the de/fr/ru/zh hint names a button that does not exist there.
- **Changing one key across all 5 locales: script it** — line-based rewrite of the matched `"key":` lines plus a `json.load` check per file, not 5×N hand-edits. Key order and formatting stay byte-identical, and a mistyped key fails loudly instead of silently editing nothing.
- **Verify a string change actually shipped**: probe the built DLL for the new text and the absence of the old (`python3 -c "print(b'…' in open('…/WrathTactics.dll','rb').read())"`). Locale JSONs are EmbeddedResources, and `dotnet build` has been observed skipping a rebuild.
