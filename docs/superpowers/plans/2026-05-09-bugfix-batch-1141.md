## Task 2: Fix hardcoded `<= 9` in `CountAvailableSlotsAboveLevel` (HIGH)

**Files:**
- Modify: `WrathTactics/Engine/ConditionEvaluator.cs:987-993`

**Bug:** Loop hardcodes `<= 9`. CLAUDE.md is explicit: "loop to `book.MaxSpellLevel`. Mythic books cap at 10. Never hardcode." Mythic-caster's level-10 slots are invisible to `SpellSlotsAboveLevel` conditions.

**Repro:** Mythic-9 caster with level-10 slot remaining, `SpellSlotsAboveLevel >= 1 with minLevel=8` rule — current code only counts levels 8 and 9, returns wrong total when only level 10 has slots.

- [ ] **Step 1: Replace the loop with per-spellbook MaxSpellLevel iteration**

Replace lines 987-993 in `ConditionEvaluator.cs`:

```csharp

            int total = 0;
            // Iterate per spellbook so mythic books (MaxSpellLevel=10) are covered.
            // Hardcoding 9 silently dropped mythic level-10 slots.
            foreach (var book in unit.Spellbooks) {
                int max = book.MaxSpellLevel;
                for (int l = minLevel; l <= max; l++) {
                    total += CountAvailableSlotsAtLevel(unit, l);
                }
            }
            return total;
        }
```

Wait — `CountAvailableSlotsAtLevel` already iterates `unit.Spellbooks` internally; the new outer loop would double-count. Verify by reading `CountAvailableSlotsAtLevel`'s body first.

- [ ] **Step 2: Read `CountAvailableSlotsAtLevel` to confirm its scope**

```bash
grep -n -A 20 "static int CountAvailableSlotsAtLevel" WrathTactics/Engine/ConditionEvaluator.cs
```

If it iterates `unit.Spellbooks` internally, the fix is to walk **the maximum** of all spellbooks' `MaxSpellLevel`, NOT to wrap the call in a per-book loop. Replace lines 987-993 with:

```csharp
        static int CountAvailableSlotsAboveLevel(UnitEntityData unit, int minLevel) {
            int total = 0;
            // Use the highest MaxSpellLevel across the unit's books — mythic books cap at 10.
            // Hardcoding 9 silently dropped mythic level-10 slots.
            int maxLevel = 0;
            foreach (var book in unit.Spellbooks) {
                if (book.MaxSpellLevel > maxLevel) maxLevel = book.MaxSpellLevel;
            }
            for (int l = minLevel; l <= maxLevel; l++) {
                total += CountAvailableSlotsAtLevel(unit, l);
            }
            return total;
        }
```
